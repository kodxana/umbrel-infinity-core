# Security policy

This repository maintains unofficial Umbrel packaging, not the upstream proprietary applications. Report defects in upstream audio applications directly to their vendors.

For packaging vulnerabilities, use a private reporting channel where available. Do not post credentials, device IDs, private network addresses, security tokens or unredacted logs in public issues.

The app integrations require trusted local networking and may access audio hardware. Review [operational security notes](docs/OPERATIONS.md) before deployment.
